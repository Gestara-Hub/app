# Skills do Projeto

Este diretorio esta reservado para definicoes futuras de skills do GestaraHub.

As skills devem transformar decisoes recorrentes do projeto em instrucoes reutilizaveis para desenvolvimento, revisao e refinamento.

## Skills previstas

- Product skill: contexto de produto, escopo e linguagem.
- Frontend skill: padroes de UI, mocks, rotas e componentes.
- Technical skill: arquitetura, testes, backend, contratos e convencoes.
