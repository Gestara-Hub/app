# Cobranças
Onde: /classes/billing

## Ver o que está em aberto
Guia: /classes/billing
+ texto "Cobranças": Aqui ficam as cobranças do mês escolhido, agrupadas por aluno.
+ botão "Escolher mês": Troque o mês para ver outras cobranças.
+ botão "Em atraso": Mostra só quem está com cobrança vencida.
+ campo "Buscar aluno": Digite o nome para achar um aluno.
Em Cobranças, filtre por mês e situação (a receber, em atraso, pagas, isentas e encerradas). O topo resume quanto há a receber e quanto está atrasado.

## Marcar como pago
Guia: /classes/billing
+ botão "Ver cobranças": Abra as cobranças do aluno.
+ botão "Ações de": Abra o menu da cobrança que foi paga.
+ item "Marcar pago": Escolha esta opção para registrar o pagamento.
+ campo "Forma de pagamento": Escolha como o aluno pagou: Pix, dinheiro, cartão ou outra.
+ botão "Registrar pagamento": Confirme para dar baixa na cobrança.
No menu ⋮ da cobrança, "Marcar pago". Escolha a forma (Pix, dinheiro, cartão ou outra), a data e, se quiser, anexe o comprovante. Dá para desfazer o pagamento depois, com confirmação.

## Desfazer um pagamento
Guia: /classes/billing
+ botão "Pagas": Veja só as cobranças já pagas.
+ botão "Pagas": Na linha da cobrança, o botão de seta volta o pagamento. Confirme e ela fica em aberto.
Cobrança paga online (Pix ou cartão pelo sistema) não permite desfazer.

## Lembrar no WhatsApp
Guia: /classes/billing
+ botão "Em atraso": Veja quem está com cobrança vencida.
+ botão "Ver cobranças": Abra as cobranças do aluno.
+ botão "Ações de": Abra o menu da cobrança.
+ item "Lembrar no WhatsApp": Abre a conversa com a mensagem pronta para enviar.
No menu ⋮, "Lembrar no WhatsApp" abre a conversa com o texto pronto. Para aluno menor, a mensagem vai ao responsável financeiro.

## Cobrança avulsa
Guia: /classes/billing
+ botão "Nova cobrança": Clique aqui para criar uma cobrança única.
+ campo "Aluno": Escolha o aluno que vai pagar.
+ campo "Descrição": Diga o que está sendo cobrado.
+ campo "Valor": Informe o valor total.
+ campo "Vencimento": Escolha a data de vencimento.
+ botão "Adicionar": Salve para lançar a cobrança.
Na ficha do aluno ou em Cobranças, "Nova cobrança" cria uma cobrança única, à vista ou parcelada. Para parcelar, escolha o número em "Parcelas".

## Gerar as mensalidades
As mensalidades nascem sozinhas todo dia, pela regra de cada aluno. Em Cobranças você vê o que já foi gerado no mês. Para algo fora da regra, use "Nova cobrança".

## Cancelar uma cobrança
Guia: /classes/billing
+ botão "Ver cobranças": Abra as cobranças do aluno.
+ botão "Ações de": Abra o menu da cobrança que quer cancelar.
+ item "Cancelar cobrança": Escolha esta opção e confirme o cancelamento.
No menu ⋮, "Cancelar cobrança". Cobrança paga não se cancela: desfaça o pagamento antes. Se cancelou sem querer, use "Reverter cancelamento" no mesmo menu.
