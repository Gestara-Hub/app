# Evolução, graduação e notas
Onde: /clients

## Trilha de evolução
Guia: /classes/modalities
+ botão "Ações de": Abra o menu da modalidade que terá trilha.
+ item "Editar / Trilha|Editar": Abra a modalidade para editar.
+ texto "Trilha de": Ligue a chave desta parte para ter trilha de evolução.
+ botão "Personalizar regras e níveis": Escolha o modelo da trilha e ajuste os níveis.
+ botão "Salvar": Clique aqui para guardar a trilha.
Cada modalidade pode ter uma trilha (faixas, níveis, módulos ou fases). Em Modalidades, edite a modalidade e escolha o modelo de trilha.

## Graduar ou avançar
Guia: /clients
+ campo "Buscar aluno": Procure o aluno que vai avançar.
+ lista "aluno cadastrado|alunos cadastrados": Clique no nome do aluno para abrir a ficha.
+ botão "Evolução": Abra a seção de evolução do aluno.
+ botão "Graduação|Níveis|Módulos|Fases": Abra a trilha do aluno nesta modalidade.
+ botão "Graduar|Avançar": Clique para registrar o avanço.
+ botão "Confirmar": Confira a data e quem avaliou, e confirme.
Na ficha do aluno, seção Evolução, abra a graduação (ou os níveis) e registre o avanço, com a data e quem avaliou. Quem dá aula pode graduar os alunos das próprias turmas.

## Ajustar o ponto de partida
Resumo: Informe em que nível um aluno antigo já estava ao entrar.
Guia: /clients
+ campo "Buscar aluno": Procure o aluno.
+ lista "aluno cadastrado|alunos cadastrados": Clique no nome do aluno para abrir a ficha.
+ botão "Evolução": Abra a seção de evolução.
+ botão "Graduação|Níveis|Módulos|Fases": Abra a trilha do aluno.
+ botão "Ajustar ponto de partida": Informe o nível e a data em que ele já estava.
Para um aluno que já tinha nível antes de usar o sistema, abra a trilha dele e use "Ajustar ponto de partida".

## Registros de aula
Guia: /clients
+ campo "Buscar aluno": Procure o aluno.
+ lista "aluno cadastrado|alunos cadastrados": Clique no nome do aluno para abrir a ficha.
+ botão "Evolução": Abra a seção de evolução.
+ botão "Registros de aula": Abra os registros desta modalidade.
+ campo "Anotação da aula": Escreva como o aluno foi na aula.
+ botão "Registrar": Clique aqui para guardar o registro.
Anote observações e pontos fortes do aluno em "Registros de aula".

## Metas do aluno
Resumo: Crie metas de treino para o aluno acompanhar.
Guia: /clients
+ campo "Buscar aluno": Procure o aluno.
+ lista "aluno cadastrado|alunos cadastrados": Clique no nome do aluno para abrir a ficha.

Nos registros de aula, use "Nova meta". Cada meta pode ter uma quantidade a atingir ou ser só marcada como feita.

## Criar uma avaliação da turma
Resumo: Crie uma prova ou trabalho para lançar notas da turma.
Guia: /classes
+ lista "turma cadastrada|turmas cadastradas": Escolha a turma na lista e clique nela para abrir.
+ aba "Avaliações": Abra a aba de avaliações da turma.
+ botão "Nova avaliação": Clique para criar uma prova ou trabalho.
+ campo "Nome": Escreva o nome da avaliação.
+ botão "Adicionar": Clique aqui para salvar.
Em modalidades com avaliações ligadas (idiomas, música e cursos livres), crie avaliações na aba Avaliações da turma.

## Lançar notas
Guia: /classes
+ lista "turma cadastrada|turmas cadastradas": Escolha a turma na lista e clique nela para abrir.
+ aba "Avaliações": Abra a aba de avaliações da turma.
+ botão "Ações de": Abra o menu da avaliação.
+ item "Lançar notas": Escolha esta opção para dar a nota de cada aluno.
+ botão "Salvar": Clique aqui para guardar as notas.
Abra a avaliação, escolha "Lançar notas" e dê a nota de cada aluno matriculado.

## Ver o boletim do aluno
Resumo: Veja as notas e a média do aluno.
Guia: /clients
+ campo "Buscar aluno": Procure o aluno.
+ lista "aluno cadastrado|alunos cadastrados": Clique no nome do aluno para abrir a ficha.
+ botão "Evolução": Abra a seção de evolução.
+ botão "Notas": Veja as notas e a média do aluno.
O boletim fica na ficha do aluno, no botão "Notas" da seção Evolução. O botão só aparece em modalidades com avaliações.

## Troca de nível pela idade
Quando o aluno passa da idade da faixa, o sistema avisa no sino para escolher o nível da nova faixa etária.
