# Equipe, usuários e permissões
Onde: /team

## Equipe (quem dá aula)
Resumo: Cadastre quem dá aula, com as modalidades que leciona.
Guia: /team
+ botão "Novo profissional": Clique aqui para cadastrar quem dá aula.
+ campo "Nome": Escreva o nome completo.
+ campo "Modalidades que leciona": Escolha as modalidades que a pessoa ensina.
+ campo "Cargo": Escolha ou crie o cargo, se quiser. Ele é opcional.
+ botão "Adicionar": Clique aqui para salvar.
Em Equipe, "Novo instrutor" ou "Novo professor" (a palavra segue a área). Informe o nome, as modalidades que leciona e, se quiser, libere o acesso ao sistema.

## Editar, inativar ou reativar quem dá aula
Resumo: Use o menu da linha para editar, inativar ou reativar.
Guia: /team
+ campo "Buscar": Procure a pessoa pelo nome ou cargo.
+ botão "Ações de": Abra o menu da pessoa.
+ item "Editar|Inativar|Reativar": Escolha o que fazer. Editar abre o cadastro.

## Cargos
Resumo: Crie e organize os cargos da equipe.
Guia: /team
+ botão "Cargos": Clique aqui para ver e organizar os cargos.

## Usuários
Resumo: Convide pessoas por e-mail e escolha o perfil de acesso.
Guia: /users
+ botão "Novo usuário": Clique aqui para convidar alguém.
+ campo "Nome": Escreva o nome completo.
+ campo "E-mail": Escreva o e-mail. O convite chega nele.
+ campo "Perfil de acesso": Escolha o que a pessoa pode fazer.
+ botão "Adicionar": Clique aqui para enviar o convite.
Em Usuários, convide pessoas por e-mail. Os perfis são Proprietário, Gerente, Atendente e o perfil de quem dá aula (Instrutor ou Professor).

## Inativar ou reativar um usuário
Resumo: Tire ou devolva o acesso de uma pessoa.
Guia: /users
+ botão "Ações de": Abra o menu do usuário.
+ item "Inativar|Reativar": Escolha tirar ou devolver o acesso. O sistema pede confirmação.

## O que cada perfil faz
Resumo: Proprietário, gerente, atendente e professor: o que cada um pode fazer.
- Proprietário: tudo, inclusive o plano do GestaraHub.
- Gerente: opera o dia a dia, financeiro e usuários, menos o plano.
- Atendente: alunos, matrículas, chamada, cobranças (ver) e mensagens.
- Quem dá aula: vê as próprias turmas, faz a chamada, avalia e gradua os alunos dele. Vê a ficha dos alunos dele, sem dinheiro. Recebe o sino com faltas seguidas e aniversários dos alunos dele.

## Convite
Resumo: A pessoa cria a senha pelo e-mail, e dá para reenviar.
Guia: /users
+ botão "Ações de": Abra o menu do usuário que ainda não entrou.
+ item "Reenviar convite": Clique aqui para mandar o e-mail de novo.
A pessoa recebe um e-mail para criar a senha. Dá para reenviar o convite em Usuários. Quem é convidado entra só no espaço que convidou.

## Auditoria
Resumo: Proprietário e gerente veem quem fez o quê, e quando.
Em Auditoria o proprietário e o gerente veem quem fez o quê, e quando.
