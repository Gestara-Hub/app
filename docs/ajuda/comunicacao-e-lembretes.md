# Comunicação, WhatsApp e lembretes
Onde: /communication

## Como o WhatsApp funciona
No plano Grátis, o envio é assistido: o sistema monta a mensagem e abre o WhatsApp do seu aparelho com o texto pronto, e você só envia. No plano Profissional, com o WhatsApp oficial conectado, as mensagens saem sozinhas.

## Enviar uma mensagem
Resumo: Escolha os alunos, escreva o texto e envie pelo WhatsApp.
Guia: /communication
+ botão "Nova mensagem": Clique aqui para escrever uma mensagem.
+ campo "Alunos": Escolha um ou vários alunos. Há "Selecionar todos com WhatsApp".
+ campo "Mensagem": Escreva o texto. Use {aluno} para o nome de cada um.
+ botão "Abrir no WhatsApp|Enviar|Começar o envio": Clique aqui para abrir o WhatsApp com a mensagem pronta.
Em Comunicação, "Nova mensagem". Escolha um ou vários alunos (há "Selecionar todos com WhatsApp"), escreva o texto e use {aluno} para o nome. Com vários, o envio segue em sequência: um toque por aluno.

## Modelos
Resumo: Veja a prévia de cada aviso e ligue o envio automático.
Guia: /communication
+ aba "Mensagens": Aqui ficam os modelos de aviso.
+ botão "Configurar modelo": Abra o modelo para ver a prévia e as opções.
+ campo "Envio automático": Ligue ou desligue o envio sozinho deste aviso.
+ botão "Salvar": Clique aqui para guardar.
Na aba Mensagens, cada aviso (atraso, vence hoje, aniversário, pacote acabando...) tem um texto padrão aprovado pelo WhatsApp, que não muda. Abra o modelo para ver como o aluno recebe: o nome, os valores e os links entram sozinhos no envio.

## Envio automático de um aviso
Resumo: Com o WhatsApp oficial, ligue o aviso para sair sozinho.
Guia: /communication
+ aba "Mensagens": Abra a lista de modelos.
+ botão "Configurar modelo": Abra o aviso que deve sair sozinho.
+ campo "Envio automático": Ligue aqui. Só funciona com o WhatsApp oficial conectado.
+ campo "Horário de envio": Escolha a hora em que o aviso sai.
+ botão "Salvar": Clique aqui para guardar.

## Horário do envio automático
Resumo: Defina o intervalo do dia em que as mensagens automáticas saem.
Guia: /communication
+ aba "Conexão": Aqui ficam as opções do WhatsApp.
+ campo "De": Escolha a hora em que o envio automático começa.
+ campo "Até": Escolha a hora em que ele termina.
+ botão "Salvar": Clique aqui para guardar o horário.
Fora desse horário, as mensagens automáticas esperam.

## Lembretes (o sino)
Resumo: O sino mostra o que lembrar hoje, com WhatsApp pronto.
Guia: /dashboard
+ botão "Lembretes": Clique no sino para ver o que lembrar hoje.
+ botão "Ver": Abra a linha do lembrete para ver os alunos e as ações.
+ botão "Mandar mensagem|Cobrar|Avisar|Mandar parabéns": Clique no WhatsApp do aluno para abrir a mensagem pronta.
+ botão "Mais ações de": Abra este menu para adiar ou não lembrar daquele aluno.
+ item "Lembrar amanhã|Não lembrar deste": Escolha adiar para amanhã ou tirar o aluno da lista.
O sino no topo mostra o que lembrar hoje: mensalidades em atraso ou perto de vencer, pacotes acabando, faltas seguidas e aniversários. Cada item tem o botão do WhatsApp; no menu você pode adiar para amanhã ou não lembrar daquele aluno. "Enviar em sequência" percorre o grupo todo.

## Enviar em sequência
Resumo: Percorra um grupo de lembretes enviando um aluno por vez.
Guia: /dashboard
+ botão "Lembretes": Abra o sino.
+ botão "Enviar em sequência": Clique aqui para percorrer todo o grupo, um aluno por vez.

## Histórico
Resumo: Veja as mensagens abertas ou enviadas e o status de cada uma.
Guia: /communication
+ aba "Histórico": Aqui ficam as mensagens abertas ou enviadas.
+ campo "Status": Filtre por status, como Entregue ou Falhou.
+ campo "Tipo": Filtre por tipo, como Cobrança ou Avulsa.
+ botão "Ações da mensagem|Ações": Abra o menu para ver a mensagem ou reenviar.
A aba Histórico lista as mensagens abertas ou enviadas, com o status.
