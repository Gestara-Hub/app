# Decisoes Tecnicas

## Decisao

As decisoes tecnicas detalhadas serao documentadas depois da analise da estrutura atual do frontend e do backend.

## Direcao inicial

- Retomar o projeto com foco em frontend-first.
- Nao descartar o backend existente sem analise.
- Preservar a ideia de organizacao, unidade e permissoes.
- Usar documentacao de produto como fonte antes de implementar telas.

## Pendencias

- Analisar `gestarahub-web`.
- Analisar `gestarahub-api`.
- Identificar decisoes ja implementadas no IAM/backend.
- Criar skill tecnica do projeto.
- Criar spec de frontend mais detalhada.
